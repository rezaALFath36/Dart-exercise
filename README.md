# Dart Exercise Repository

This repository contains a collection of exercise codes for learning the fundamentals of the **Dart** programming language. Each file focuses on mastering a specific concept, ranging from basic logic (control flow and loops), functions, and data collections, to Object-Oriented Programming (OOP).

## Tools Requirement
### 1. DartPad (Tool I use right now)
* You can access DartPad open source by clicking this link
  https://dartpad.dev/


## Table of Contents & Topics

To make navigation easier, here is the categorization of the exercise files based on their programming topics:

### 1. Loops (Iteration)
Practicing flow control and loops in Dart.
* `forLooping.dart` - Basic exercises using `for` loops.
* `whileLooping.dart` - Basic exercises using `while` loops.
* `ListLooping.dart` & `listLooping2.dart` - Iterating through data inside a List, including calculation logic (such as calculating average expenses).

### 2. Conditionals (Control Flow)
Exercises regarding decision-making statements in code.
* `switch.dart` - Implementing conditional logic using `switch-case`.
* `listCondition.dart` & `listCondition2.dart` - Applying conditional statements to manipulate List data.

### 3. Collections (Data Structures)
Learning how to manage and structure grouped data.
* `ListSkorGame.dart` & `ListSkorGame2.dart` - Case studies on storing and updating game score data within a List.
* `mapping.dart` & `mapping2.dart` - Implementing key-value pairs using the `Map` data type.

### 4. Functions
Practicing modular code creation and reusability.
* `functionTraining.dart` - The basics of declaring and calling functions.
* `functionNamedParameter.dart` - Implementing functions that utilize *named parameters* for more flexible arguments.

### 5. Null Safety
Understanding data security and handling null values in modern Dart.
* `nullSafety.dart` - Introduction to nullable and non-nullable variables.
* `nullSafetyCondition.dart` - Handling logical conditions when dealing with null values.

### 6. Object-Oriented Programming (OOP)
* `oopFirstTraining.dart` - Initial exercises on creating classes, objects, properties, and methods.

### 7. Comprehensive Case Studies (Final Projects)
* `finalExercise.dart` & `finalExercisePart2.dart` - Comprehensive exercises combining multiple concepts above (such as game pricing features and shopping cart functionality).
